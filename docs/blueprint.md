# **App Name**: Edumate Pro

## Core Features:

- Personalized Dashboard: Student Dashboard: Personalized view of active subscriptions, purchased courses, and submitted assignments.
- Instructor Dashboard: Instructor Dashboard: Clean display of enrolled students, uploaded lessons, and pending assignment requests.
- Payment Integration: Payment Integration: Secure and styled payment processing with clear success and feedback messages.
- Content Summarization: AI-Driven Content Summarization: Generate brief summaries of video lessons to allow students to determine relevance. The tool considers course context and previous activity to select the most relevant lessons for summary.
- Responsive Layout: Responsive Design: Ensures seamless usability and adapts fluidly across devices with touch-friendly components.

## Style Guidelines:

- Primary color: Royal Purple (#6A1B9A) for main interactive elements to communicate sophistication and intelligence.
- Background color: Light Gray (#F9FAFB), a very pale near-white, to communicate cleanliness, promote visual clarity and provide good contrast with darker text. The lightness is at HSL 0, 0, 97.
- Accent color: Teal (#349888), an analogous color, with higher saturation than the Royal Purple and very close brightness, so that it creates a contrasting visual highlight.
- Body and headline font: 'Inter', a sans-serif known for its modern and readable design.
- Use futuristic and minimalist icons for enhanced visual appeal and clarity.
- Implement purposeful spacing and clean layering to create an intelligent and intuitive layout flow.
- Incorporate smooth transitions and subtle animations using Framer Motion to create a dynamic user experience.
